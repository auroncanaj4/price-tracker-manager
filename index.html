How to create the token (once)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories and pick just this repo.
  3. Permissions: Contents: Read and write. For the Run now button also Actions: Read and write.
  4. Paste it above. It is stored only in this browser (localStorage) and sent only to api.github.com.
